# Manual Definitivo: Agente de Nutrição e Treino (n8n + Supabase + Discord)

> **Objetivo:** Construir um agente de IA focado em dieta e treino, operando 100% com custo zero e integrado via slash commands no Discord.
>
> **Entendendo a Separação de Responsabilidades:**
> *   **Supabase Storage:** Funciona como o seu "Google Drive". Guarda os arquivos PDFs inteiros.
> *   **Supabase pgvector (Tabela):** O "cérebro" da IA. Guarda fatias de texto traduzidas para números (vetores) que o Gemini consegue ler e comparar.
> *   **n8n Cloud:** O maestro. Faz o download do Storage, fatiamento, envio para o Gemini e gerenciamento de conversas.

---

## FASE 1: Preparando o Banco de Dados (Supabase)

### 1. Criando o Projeto e a Tabela
1. Acesse o Supabase e crie um novo projeto.
2. No menu lateral, vá em **SQL Editor** e clique em *New Query*.
3. Cole o código abaixo e clique em **Run** para criar a extensão de IA e a tabela que vai guardar o conhecimento:

```sql
-- 1. Ativar extensão de vetores
create extension if not exists vector with schema extensions;

-- 2. Criar tabela de documentos científicos (Adaptada para os 768 vetores do Gemini)
create table if not exists public.scientific_documents (
    id bigint generated by default as identity primary key,
    content text not null,
    metadata jsonb not null default '{}'::jsonb,
    embedding extensions.vector(768),
    created_at timestamptz not null default now()
);

-- 3. Criar função que a IA vai usar para pesquisar na tabela
create or replace function public.match_scientific_documents(
    query_embedding extensions.vector(768),
    match_count int default 8,
    filter jsonb default '{}'::jsonb
)
returns table (id bigint, content text, metadata jsonb, similarity float)
language sql stable
as $$
    select d.id, d.content, d.metadata, 1 - (d.embedding <=> query_embedding) as similarity
    from public.scientific_documents d
    where d.metadata @> filter
    order by d.embedding <=> query_embedding
    limit match_count;
$$;
```

### 2. Criando a Pasta dos PDFs (Storage)
1. No menu lateral do Supabase, vá em **Storage**.
2. Clique em **New Bucket** e nomeie como `scientific-library`.
3. Mantenha-o **Privado** (não marque a caixa de *Public bucket*).
4. Faça o upload manual de alguns PDFs científicos para dentro deste bucket para podermos testar.

## FASE 2: Conectando Tudo (Credenciais no n8n)

Para o n8n conversar com o Google e com o Supabase sem bloqueios, precisamos cadastrar as "chaves da porta".

### 1. Credencial do Google Gemini
1. Vá no [Google AI Studio](https://aistudio.google.com/), crie um projeto e gere uma **API Key**.
2. No n8n, menu lateral esquerdo, clique em **Credentials** > **Add Credential**.
3. Busque por `Google Gemini API`.
4. Cole sua API Key, dê um nome (ex: `Gemini Free Tier`) e salve.

### 2. Credenciais do Supabase (Atenção Máxima Aqui)
No n8n, você vai precisar de duas conexões diferentes com o Supabase: uma genérica (para usar nos nós de IA) e uma de API (para baixar os PDFs).

**A. Pegando os dados no Supabase:**
1. No Supabase, vá em **Project Settings** (ícone de engrenagem) > **API**.
2. Copie a **Project URL** (ex: `https://xyz.supabase.co`).
3. Copie a **service_role secret key** (NUNCA use a chave `anon/public` para baixar arquivos privados).

**B. Cadastrando a Conexão de IA no n8n:**
1. Em **Credentials**, busque por `Supabase API`.
2. Cole a **Project URL** no campo *Host* (remova o `https://`).
3. Cole a **service_role secret** no campo *Service Role Secret*.
4. Salve como `Supabase Database`.

## FASE 3: Workflow 1 — Lendo PDFs e Ensinando a IA (RAG)

Neste fluxo, o n8n vai olhar o seu bucket `scientific-library`, listar todos os PDFs, baixar um por um e indexar no banco vetorial.

### Passo a Passo no Canvas do n8n:

1. **Adicione um nó `Manual Trigger`.**
2. **Adicione um nó `HTTP Request` (Para listar os arquivos):**
   * Ligue-o pelo lado direito do Manual Trigger.
   * **Method:** `POST`
   * **URL:** `https://SUA_PROJECT_URL.supabase.co/storage/v1/object/list/scientific-library`
   * **Authentication:** `None`
   * **Send Headers:** Ative. Name: `Authorization` / Value: `Bearer SUA_SERVICE_ROLE_KEY`
   * **Send Body:** Ative. Selecione `JSON` e cole: `{"prefix": "", "limit": 100, "offset": 0}`
3. **Adicione um nó `Item Lists` (Para separar os arquivos):**
   * Ligue-o pelo lado direito do HTTP Request anterior.
   * **Operation:** `Split Out Items`.
   * **Field To Split Out:** `name`.
4. **Adicione outro nó `HTTP Request` (Para baixar o PDF da vez):**
   * Ligue-o pelo lado direito do Item Lists.
   * **Method:** `GET`
   * **URL:** `https://SUA_PROJECT_URL.supabase.co/storage/v1/object/authenticated/scientific-library/{{ $json.name }}`
   * **Authentication:** `None`
   * **Send Headers:** Ative. Name: `Authorization` / Value: `Bearer SUA_SERVICE_ROLE_KEY`
   * **Lá no final do nó, em Add Option > Response Format:** Mude para `File`.
5. **Adicione o nó `Supabase Vector Store` (O Motor da IA):**
   * Ligue-o pelo lado direito do HTTP Request anterior.
   * **Operation:** `Insert Documents`.
   * **Credential:** Selecione a credencial `Supabase Database` que você criou.
   * **Table Name:** `scientific_documents`.

### Conectando as "Ferramentas" embaixo do nó do Supabase:
Observe que o nó do Supabase tem "pontos de encaixe" na parte inferior dele.
1. No encaixe inferior chamado **Document**, puxe uma linha e adicione o nó **Default Data Loader**.
2. Abaixo do nó *Default Data Loader*, no encaixe **Text Splitter**, conecte o nó **Recursive Character Text Splitter**. Configure: *Chunk Size: 1200* e *Chunk Overlap: 200*.
3. De volta ao nó principal do Supabase, no encaixe inferior chamado **Embeddings**, conecte o nó **Google Gemini Embeddings**. Selecione a credencial do Google e o modelo `gemini-embedding-001` (ou `text-embedding-004`).

**Como usar:** Salve o workflow e clique em "Test Workflow". Ele vai baixar os PDFs e preencher sua tabela `scientific_documents` no Supabase.

## FASE 4: Workflow 2 — O Bot no Discord

Este é o fluxo que fica rodando 24/7 esperando mensagens do Discord.

### Passo a Passo da Lógica:

1. **Adicione o nó `Webhook` (A porta de entrada):**
   * **HTTP Method:** `POST`.
   * **Path:** `discord-bot` (ou o que preferir).
   * **Respond:** `Using 'Respond to Webhook' Node` (Isso é obrigatório).
   * Aba **Options**: Ative `Raw Body` (Isso é obrigatório para a segurança do Discord).
2. **Adicione o nó `Code` (Validação de Segurança):**
   * Conecte ao lado do Webhook.
   * Copie a **Public Key** do seu bot lá no Discord Developer Portal.
   * Cole este código Javascript (substituindo a chave):
   ```javascript
   const crypto = require('crypto');
   const PUBLIC_KEY_HEX = 'COLOQUE_AQUI_A_PUBLIC_KEY'; // Troque aqui!

   const headers = $input.item.json.headers || $input.item.headers;
   const signature = headers['x-signature-ed25519'];
   const timestamp = headers['x-signature-timestamp'];

   const rawBody = $getWorkflowStaticData
     ? JSON.stringify($input.item.json.body ?? $input.item.json)
     : JSON.stringify($input.item.json);

   const message = Buffer.from(timestamp + rawBody, 'utf-8');
   const publicKeyDer = Buffer.concat([
     Buffer.from('302a300506032b6570032100', 'hex'),
     Buffer.from(PUBLIC_KEY_HEX, 'hex'),
   ]);
   const publicKey = crypto.createPublicKey({ key: publicKeyDer, format: 'der', type: 'spki' });
   const valida = crypto.verify(null, message, publicKey, Buffer.from(signature, 'hex'));

   return [{ json: { ...($input.item.json.body ?? $input.item.json), _assinatura_valida: valida } }];
   ```
3. **Adicione o nó `If` (Avaliando a Assinatura):**
   * Conecte ao Code.
   * **Condition:** `{{ $json._assinatura_valida }}` is `true`.
4. **Adicione o nó `Respond to Webhook` (Discord ACK):**
   * Conecte na saída **True** do IF.
   * **Respond With:** `JSON`.
   * **Response Body:** `{"type": 5}` (Isso avisa o Discord que o bot está "pensando").
5. **Adicione o nó `AI Agent` (O Cérebro):**
   * Conecte ao Respond to Webhook.
   * Ele vai rodar em background enquanto o Discord espera.
6. **Conecte os sub-nós na parte inferior do AI Agent:**
   * **Model:** Conecte o `Google Gemini Chat Model` (selecione `gemini-3.1-flash-lite`).
   * **Memory:** Conecte o `Postgres Chat Memory`.
     * *Session ID:* `{{ $json.member.user.id }}` (Isso garante que cada usuário tenha sua própria memória).
   * **Tools:** Conecte a ferramenta `Vector Store Question Answer`.
     * Onde ela pede Vector Store, conecte um `Supabase Vector Store` configurado como *Get ranked documents* (apontando para `scientific_documents`), e embaixo dele coloque o mesmo `Google Gemini Embeddings` que usamos no Workflow 1.
   * **Tools (Matemática):** Conecte um `Code Tool`. Escolha Python e cole o código de cálculos de TMB/Macros definido na versão anterior deste documento.
7. **Adicione um nó `HTTP Request` (Enviando a resposta final):**
   * Conecte ao lado direito do AI Agent.
   * **Method:** `PATCH`
   * **URL:** `https://discord.com/api/v10/webhooks/{{ $json.application_id }}/{{ $json.token }}/messages/@original`
   * **Send Body:** Ative. Mude para JSON.
   * **Body:** `{"content": "{{ $json.output }}"}`

### Resumo do Fluxo do Agente:
O Discord bate no Webhook ➜ O Código confere a chave ➜ O n8n grita "Tô pensando!" pro Discord ➜ O Gemini pega os dados, faz as contas no Python, lê os artigos no Supabase ➜ O n8n empurra a resposta pronta de volta pro chat do Discord.

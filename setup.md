# Guia de Configuração e Instalação (Setup)

## Pré-requisitos
* Instância do **n8n** rodando (Self-hosted ou Cloud).
* Conta no **Supabase** com acesso ao SQL Editor.
* Chave de API do **Google AI Studio** (`GEMINI_API_KEY`).
* Token de Bot do **Telegram** gerado pelo `@BotFather`.

---

## 1. Configuração do Banco de Dados (Supabase)

Acesse o **SQL Editor** do Supabase e execute os scripts na ordem abaixo:

### A. Criar Schemas e Tabelas
```sql
CREATE SCHEMA IF NOT EXISTS app;
CREATE SCHEMA IF NOT EXISTS rag;
CREATE EXTENSION IF NOT EXISTS vector;

CREATE TABLE IF NOT EXISTS app.usuarios (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  telegram_id TEXT UNIQUE NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS app.perfis (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  usuario_id BIGINT REFERENCES app.usuarios(id) ON DELETE CASCADE,
  dados JSONB DEFAULT '{}'::jsonb,
  completo BOOLEAN DEFAULT FALSE,
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  CONSTRAINT unique_usuario_id UNIQUE (usuario_id)
);

CREATE TABLE IF NOT EXISTS app.planos (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  usuario_id BIGINT REFERENCES app.usuarios(id) ON DELETE CASCADE,
  conteudo_plano JSONB NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS rag.document_chunks (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  content TEXT NOT NULL,
  metadata JSONB DEFAULT '{}'::jsonb,
  embedding VECTOR(768)
);
```
### B. Criar Função de Busca Semântica
```sql
DROP FUNCTION IF EXISTS match_documents;

CREATE OR REPLACE FUNCTION match_documents (
  query_embedding vector(768),
  match_threshold float,
  match_count int
)
RETURNS TABLE (
  id uuid,
  content text,
  metadata jsonb,
  similarity float
)
LANGUAGE sql STABLE
AS $$
  SELECT
    rag.document_chunks.id,
    rag.document_chunks.content,
    rag.document_chunks.metadata,
    1 - (rag.document_chunks.embedding <=> query_embedding) AS similarity
  FROM rag.document_chunks
  WHERE 1 - (rag.document_chunks.embedding <=> query_embedding) > match_threshold
  ORDER BY similarity DESC
  LIMIT match_count;
$$;
```
2. Configuração de Credenciais no n8n
No painel do n8n, cadastre as seguintes credenciais em Credentials:

Postgres Credential (Supabase):

Host: db.<sua-ref>.supabase.co

Database: postgres

User: postgres

Password: Sua senha do banco Supabase.

Port: 5432 (ou 6543 para Connection Pooling).

Telegram API:

Access Token: Token fornecido pelo BotFather.

Variables (Variáveis de Ambiente do n8n):

Adicione a variável GEMINI_API_KEY com a sua chave da API do Google AI Studio.

3. Importação e Ativação do Workflow
Baixe o arquivo JSON do Workflow 1.

No n8n, vá em Workflows > Import from File e selecione o arquivo.

Vincule as credenciais registradas nos nós de Telegram e Postgres.

Alterne o interruptor do workflow no canto superior direito de Inactive para Active.
